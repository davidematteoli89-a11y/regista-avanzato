# Manual Import Point 106 Decision — P105

## Context

P105 ha preparato la checklist operativa per la produzione degli asset social/editoriali di Regista Avanzato.

Sono state definite specifiche per caroselli, stories, reel, cover articolo/newsletter, naming file, export e checklist Canva/Figma.

Non sono stati generati asset, non sono stati creati file Canva/Figma, non sono stati pubblicati contenuti e non è stato inserito alcun URL Substack inventato.

`substack_url_status=not_created_or_not_confirmed`.

## Opzioni P106

### A. P106 — First publication manual checklist

Obiettivo: preparare checklist manuale per pubblicare davvero il primo contenuto su sito/Substack/social, senza automatismi.

Usare se testi e asset sono pronti o se si vuole definire il gate di pubblicazione prima della produzione finale.

### B. P106 — Substack URL integration gate

Obiettivo: se l’URL Substack reale è disponibile, preparare link dal sito e social.

Usare solo quando l’URL reale Substack è disponibile e verificato.

### C. P106 — Canva asset generation prompt pack

Obiettivo: preparare prompt/brief finali da usare in Canva/Figma per produrre gli asset.

Usare se la priorità è passare dalla checklist a brief esecutivi visuali.

### D. P106 — Monitoring only

Obiettivo: fermarsi e monitorare sito/canali prima di creare o pubblicare altri asset.

## Decisione consigliata

Decisione consigliata: A — P106 First publication manual checklist.

Alternativa forte: C — Canva asset generation prompt pack, se la priorità operativa diventa produrre grafiche prima di impostare il gate pubblicazione.
