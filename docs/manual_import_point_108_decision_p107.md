# Manual Import Point 108 Decision — P107

## Context

P107 ha creato il manuale editoriale ufficiale di Regista Avanzato: mappa delle ispirazioni, identità, tono, voci interne, regole fonti/dati/video, anti-hype, anti-betting, strutture operative, checklist consegna e regole AI-assisted writing.

Non sono stati pubblicati contenuti, non sono stati generati asset, non è stato inventato alcun URL Substack, non sono state eseguite modifiche codice, merge, deploy, DB write, provider/import o Apify.

## P108 options

### A. P108 — Canva asset generation prompt pack

Obiettivo: preparare prompt e brief finali per creare asset grafici in Canva/Figma.

Uso consigliato se la priorità è produrre grafiche per manifesto, rubriche, primo articolo, stories e reel.

Vincoli:

- nessuna pubblicazione automatica;
- nessun asset generato senza autorizzazione;
- nessuna clip non autorizzata;
- nessun URL Substack inventato.

### B. P108 — Substack creation manual checklist

Obiettivo: preparare checklist specifica per creare realmente Substack, visto che l’URL non è ancora creato o confermato.

Uso consigliato se la priorità è fissare nome, URL reale, About page, welcome email e primo post prima delle grafiche.

Vincoli:

- nessun URL inventato;
- nessuna pubblicazione automatica;
- nessuna modifica sito senza gate dedicato.

### C. P108 — Publication execution day checklist

Obiettivo: checklist finale per il giorno di pubblicazione.

Uso consigliato solo dopo avere asset pronti e/o URL Substack reale.

### D. P108 — Monitoring only

Obiettivo: fermarsi e monitorare.

Uso consigliato se non si vuole ancora procedere con asset, Substack o pubblicazione.

## Recommended decision

- `p108_recommended=canva_asset_generation_prompt_pack_or_substack_creation_manual_checklist`

Scelta pratica:

- scegliere A se vogliamo produrre grafiche;
- scegliere B se vogliamo creare Substack prima delle grafiche.
